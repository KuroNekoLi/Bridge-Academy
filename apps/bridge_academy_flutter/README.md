# Bridge Academy — M2-F05 Flutter single-player table

A single-player Flutter bridge table using the pure Dart Bridge Core and its
privacy-filtered PlayerView, local SinglePlayerCoordinator, and optionally the
real BEN BotPolicy via HTTP. Rule logic stays outside widgets. This is a
functional first vertical slice, NOT the full M2 MVP.

## Run on macOS

    cd apps/bridge_academy_flutter
    flutter create --platforms=web,android,ios,macos --project-name=bridge_academy_flutter .
    flutter pub get
    flutter run -d chrome

The platform scaffolds are generated by Flutter, not committed. Choose
Rules demo bot (NOT BEN) to practice without any server. Demo uses a fixed
52-card board and a naive rules-only opponent; it does not call BEN.

For true BEN, start a trusted BEN API and run:

    flutter run -d chrome --dart-define=BEN_BASE_URL=http://127.0.0.1:8085

BEN must allow the appropriate Host/CORS and be reachable from the device,
not just the build machine. Android Emulator typically needs host 10.0.2.2.
Do not expose an unauthenticated BEN endpoint publicly: GET query contains
the acting Bot's authorized original hand. Use a trusted HTTPS proxy.

## Behavior delivered
- North/East/South/West compass table; hidden opponents show counts only;
  Dummy appears after opening lead.
- Human seat and Demo/Live BEN choice; level 1–7 Bid or Pass/X/XX.
- Legal hand and exposed Dummy cards tappable when authorized, marked with
  a check independent of color.
- Auction, current trick, contract, turn, completed trick counter, and signed
  NS duplicate score; four passes produce Pass Out at zero.
- English and zh-TW copy, loading, safe error/retry, no implicit BEN fallback.

## M2-F11 terminal deal replay
- Once the current game finishes, inspect chronological calls, individual cards, trick winners and final score with First/Previous/Next/Last. Replay is strictly read-only and reuses Bridge Core event application. Only authorized PlayerView frames reach Flutter; no full-hand PBN or opponent private cards are sent to the UI.
- Pass Out is replayed as four chronological Pass actions. Current-game replay disappears on restart; persistence/export are future features. [Acceptance](../../docs/m2/M2_F11_FINISHED_REPLAY_ACCEPTANCE.md), [Lesson](../../docs/learning/features/M2_F11_FINISHED_REPLAY.md).

## Trust boundary

UI gesture -> BridgeSession -> SinglePlayerCoordinator -> BridgeGame.apply ->
GameState -> PlayerView -> Flutter widget. Widgets never read raw GameState,
hidden enemy hands, complete PBN, or BEN raw server responses.

## A2.8 browser storage boundary

Web defaults to an AES-GCM encrypted local checkpoint with a browser WebCrypto-backed key and legacy plaintext checkpoint migration. Browser requires HTTPS or localhost; clearing browser/origin storage loses recovery. This is **best-effort single-key LocalStorage**, not native SQLite transaction, XSS protection or cloud backup. Android/iOS continue using encrypted SQLite. [Acceptance](../../docs/product/P1_A2_8_BROWSER_ENCRYPTED_CHECKPOINT_ACCEPTANCE.md), [Lesson](../../docs/learning/features/M2_F20_WEB_ENCRYPTED_CHECKPOINT.md).


## A4.4 Flutter server-authoritative Gateway (explicit development opt-in)

No Gateway URL is configured by default. Existing Demo/local BEN functionality stays unchanged. To see the new server-owned table in a browser, start the trusted local BEN and Gateway with `GATEWAY_BROWSER_ORIGINS=http://localhost:8000`, then from this app directory:

```bash
flutter run -d chrome --web-port=8000 \
  --dart-define=BRIDGE_GATEWAY_ORIGIN=http://127.0.0.1:8086
```

The Gateway must be separately available; this is a **localhost-only development recipe**, not public deployment. Non-loopback origins require valid HTTPS. The UI obtains a fresh anonymous Bearer token and uses `/v1/games/view/action/advance` with stable request IDs and server-controlled GameState. The token is in RAM only, so browser reload requires a new session. On ambiguous HTTP error, use `Refresh server view` then `Retry same request`; no hidden Demo fallback. [A4.4 acceptance](../../docs/product/A4_GATEWAY_A4_4_ACCEPTANCE.md), [M2-F31 lesson](../../docs/learning/features/M2_F31_FLUTTER_GATEWAY_SESSION.md). Android/iOS device UI QA remains disabled.
